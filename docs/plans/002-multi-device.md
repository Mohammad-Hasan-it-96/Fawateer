# Plan 002 — Multi Device Support

Design a secure multi-device system.

Current idea:

Manager Mode:

* Full access.
* Activated through subscription.

User Mode:

* Scan QR Code from Manager device.
* Automatically join the same business.
* Share the same account data.

Study this idea critically.

Questions:

* Is QR pairing the best solution?
* Are there better alternatives?
* How should synchronization work?
* How should permissions work?
* What happens if devices go offline?
* What happens if two devices edit the same invoice?

Analyze:

* Architecture
* Sync strategy
* Security
* Database
* User experience
* Customer support impact

Suggest the best long-term design.

No implementation.

Only planning.
